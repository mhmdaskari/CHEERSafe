    Quickstart Guide#

    This guide will help you get started with the CHEERSafe package by walking through basic usage examples.

    Installation#

    First, install the CHEERSafe package:

    # Clone the repository
git clone https://github.com/CHEER-Hub/LossModel.git
cd LossModel

# Install the package
pip install .

    Key Concepts#

    Configuration#

    The package uses a configuration system to manage analysis parameters like number of workers, iterations, and file paths.

    Core Components#

    • BuildingInventory: Manages building data and configurations
    • DamageProbabilityCalculation: Main analysis engine
    • DamageProbabilityAnalysis: Results analysis and visualization
    • Statistical Tools: Covariance and sampling utilities

    Typical Workflow#

    1. Configure analysis parameters
    2. Initialize building inventory and statistical components
    3. Set up the damage probability calculation engine
    4. Specify building types and resistance indices to process
    5. Run the analysis
    6. Aggregate and visualize results

    ### Step 3: Run Analysis

Execute the damage probability calculation:

```python
# Calculate average damage probability
myDamageProbabilityCalculation.get_average_damage_probability()

# Aggregate results for analysis
my_probabilities = myDamageProbabilityCalculation.aggregate_results()

    Step 4: Visualize Results#

    Analyze and visualize the damage probability results:

    from cheersafe.damage_probability_analysis import DamageProbabilityAnalysis

# Define analysis parameters
building_type = 2
c_index = 46

# Initialize analysis with results file
myDamageProbabilityAnalysis = DamageProbabilityAnalysis(
    prob_ds_file_path="Outputs/ProbDS_wfd_dictMaxIter50_aggregated.pkl",
    building_type=building_type,
    resistance_type=c_index
)

# Generate visualization plots
myDamageProbabilityAnalysis.plot_analysis_results()
