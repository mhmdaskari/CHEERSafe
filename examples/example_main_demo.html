    CHEERSafe Demo: Complete Hurricane Damage Analysis Workflow¶

    • CHEERSafe package installed
    • Required input files (building geometry, etc.)

    Package Configuration and Imports¶

    Configure the analysis parameters and import required modules. The configuration allows you to customize:

    • NUM_OF_WORKERS: Number of parallel workers for computation
    • NUM_OF_ITERATIONS: Number of Monte Carlo iterations
    • INPUTS_PATH: Directory containing input files
    • OUTPUTS_PATH: Directory for output files
    In [5]:
    Copied! 
    from cheersafe.config import Config

# Configure analysis parameters
Config.NUM_OF_WORKERS = 12
Config.NUM_OF_ITERATIONS = 50
Config.INPUTS_PATH = "Inputs"
Config.OUTPUTS_PATH = "Outputs"

# Import core analysis modules
from cheersafe.damage_probability_calculation import DamageProbabilityCalculation
from cheersafe.inventory import BuildingInventory
from cheersafe.tools.stats import Covariance, Sampling

    Initialize Core Components¶

    Set up the building inventory and statistical analysis tools:

    • BuildingInventory: Manages building data and configurations
    • Covariance: Handles covariance calculations for uncertainty analysis
    • Sampling: Provides sampling methods for Monte Carlo simulation

    Summary¶

    This notebook demonstrated the complete CHEERSafe workflow:

    1. Setup: Environment configuration and package imports

    3. Configuration: Analysis parameters and building type selection
    4. Calculation: Monte Carlo damage probability analysis
