    Package Configuration and Imports¶

    Configure the analysis parameters and import required modules.

    Key Configuration for This Demo:

    • EXPORT_DETAILED_DAMAGE_RATIOS = True: Enables export of detailed component-level damage ratios to CSV

    When enabled, the following columns are exported per (building_type, cindex) combination:

    • m: Building type identifier
    • c: Component configuration index
    • wind_orientation_index: Wind orientation index
    • wind_speed_index: Wind speed index
    • flood_depth_index: Flood depth index
    • dr_total: Total building damage ratio
    • dr_explicit: Explicit damage ratio (wind components)
    • dr_implicit: Implicit damage ratio (interior + flood)
    • dr_exp_wind_RC: Roof Coverings explicit damage ratio
    • dr_exp_wind_RS: Roof Sheathings explicit damage ratio
    • dr_exp_wind_RWC: Roof-Wall Connections explicit damage ratio
    • dr_exp_wind_O: Openings explicit damage ratio
    • dr_exp_wind_W: Walls explicit damage ratio
    • dr_imp_wind_I: Interior implicit damage ratio
    • dr_imp_wind_E: Electrical implicit damage ratio
    • dr_imp_wind_M: Mechanical implicit damage ratio
    • dr_imp_wind_P: Plumbing implicit damage ratio
    • dr_imp_flood: Flood implicit damage ratio
