    Damage Ratio Calculation#

    The damage ratio calculation module provides functionality for calculating damage ratios for structures.

    Bases: BaseDamageRatio

    This class represents the explicit damage ratio. It inherits from the BaseDamageRatio class.

    Attributes:#

    ResistanceValues: dict[str, np.ndarray] A dictionary that holds the resistance values for each component. The keys are the component types and the values are numpy arrays of resistance values.

    Methods:#

    post_init(): This method is called after the class is instantiated. It initializes the ResistanceValues attribute and calls the fn_damage_ratio_wind() method.

    fn_damage_ratio_wind(): This method calculates the damage ratio for each component. The damage ratio is calculated as the number of resistance values that are equal to 0 divided by the total number of resistance values. For RC and RS components, there is a threshold of 35%. If the damage ratio is greater than 35%, then the component is considered to be totaled. For walls, a new damage ratio calculation is used. The wall is considered to be failed if any of the four walls fail. If two walls fail, then the wall is considered to be totaled.
