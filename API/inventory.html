    fn_connection_coordinate #

    fn_connection_coordinate() -> tuple[ndarray, list[int]]

    Calculate the Roof-to-Wall Connection (RWC) coordinates and numbers for a building.

    This method determines the RWC coordinates and numbers based on the building's roof shape, length, and width. It supports two types of roof shapes: hip roof (1) and gable roof (2).

    Notes

    Instance attributes used:

    • RoofShape: The shape of the roof, where 1 represents a hip roof and 2 represents a gable roof.
    • BldgLength: The length of the building.
    • BldgWidth: The width of the building.

    Outputs: Updates ConnectionCoordinate and NumConnection.

    Returns:

    Type Description
    tuple[ndarray, list[int]]

    tuple[np.ndarray, list[int]]: The roof-to-wall connection coordinates and the number of connections on each side.

    Raises:

    Type Description
    ValueError

    If the roof shape is not recognized (i.e., not 1 or 2).

    fn_panel_coordinate #

    fn_panel_coordinate() -> tuple[ndarray, ndarray]

    Calculate panel coordinates, and number of panels, given building geometry.

    This method calculates the panel coordinates and the number of panels based on the building geometry. It uses the building's roof shape, sheathing width, and building length to calculate the coordinates.

    Notes

    Instance attributes used:

    • RoofShape: The roof shape, either 1 for hip roof or 2 for gable roof.
    • SheathingWidth: The width of the sheathing.
    • BldgLength: The length of the building.
    • HipRidgeAngle: The angle of the hip ridge.

    Returns:

    Type Description
    ndarray

    np.ndarray: A 2D array of the panel coordinates.
    ndarray

    np.ndarray: An array of the number of panels in each row.

    Raises:

    Type Description
    ValueError

    If the roof shape is not recognized, a ValueError will be raised.
    Outputs

    None beyond the returned value.

    instantiate_buildings_from_json #

    instantiate_buildings_from_json()

    Instantiates Building objects from a JSON file and stores them in the buildings attribute.

    The method reads a JSON file from the directory specified in the dir_of_buildings attribute, creates Building objects from the data, and stores them in the buildings attribute.

    Notes

    Instance attributes used:

    • dir_of_buildings (str): The directory where the building data is stored.
    • buildings (list[Building]): A list of Building objects representing the buildings in the inventory.

    Raises:

    Type Description
    FileNotFoundError

    If the JSON file cannot be found at the specified directory.
