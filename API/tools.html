    Covariance #

    This class provides methods for creating covariance matrices.

    The covariance matrix is computed based on the specified number of components, their mean temperatures, coefficient of variation (CV), and the inter- and intra-correlation values.

    Methods:

    Name Description
    create_cov_matrix

    Computes the covariance matrix for a set of components based on their temperature characteristics and correlation parameters.

    create_cov_matrix staticmethod #

    create_cov_matrix(
    num_component,
    temp_mean,
    temp_cv,
    inter_correlation=0.2,
    intra_correlation=0.4,
) -> ndarray

    Computes the covariance matrix for a set of components.

    This method calculates a covariance matrix based on the number of components, their mean values, and coefficient of variation (CV). It considers both inter-component and intra-component correlations.

    Parameters:

    Name Type Description Default
    num_component list[int]

    Number of elements in each component.

    		 required
    temp_mean ndarray

    Mean values for each element.

    		 required
    temp_cv ndarray

    Coefficient of variation for each element.

    		 required
    inter_correlation float

    Correlation coefficient between elements of different components. Defaults to 0.2.

    		 0.2
    intra_correlation float

    Correlation coefficient between elements of the same component. Defaults to 0.4.

    		 0.4

    Returns:

    Type Description
    ndarray

    Covariance matrix of the components.
    Outputs

    None beyond the returned value.

    		 None

    Returns:

    Type Description

    An array of generated Latin Hypercube samples.

    Examples:

    Example usage for specifying different distributions and parameters#

    Option 1: distributions_details = [ {'type': 'norm'}, {'type': 'lognorm'}, {'type': 'lognorm', 's': 1.2} ] mean = [3, 4, 2] covariance = [[1, 0.5, 0.3], [0.5, 1, 0.2], [0.3, 0.2, 1]]

    Option 2: distributions_details = [{'type': 'norm'}] # All variables use the 'norm' distribution mean = [3, 4, 2] covariance = [[1, 0.5, 0.3], [0.5, 1, 0.2], [0.3, 0.2, 1]]

    filter_column_values_df classmethod #

    filter_column_values_df(
    df: DataFrame, column_name: str, **kwargs
) -> ndarray

    Filters a pandas DataFrame based on the conditions provided in the keyword arguments, selects a specified column, and returns it as a numpy array.

    This method allows for dynamic filtering of a DataFrame based on multiple conditions. Each condition is applied to a specified column, and the results are used to filter the DataFrame. After filtering, values from a specified column are extracted and returned as a numpy array.

    Parameters:

    Name Type Description Default
    df DataFrame

    The DataFrame to be filtered.

    		 required
    column_name str

    The name of the column to be selected after filtering.

    		 required
    **kwargs dict

    Variable length keyword arguments, where each keyword represents a column in the DataFrame and the corresponding value represents the condition for filtering. Conditions should be provided in a way that they can be evaluated directly in a query.

    		 {}

    Returns:

    Type Description
    ndarray

    np.ndarray: The selected column values after filtering, converted to a numpy array.

    None beyond the returned value.

    from_json classmethod #

    from_json(
    path_to_file: str, dict_key: str = None
) -> Union[ndarray, Dict[str, Any]]

    Reads data from a JSON file and returns it as a numpy array or dictionary.

    This method opens and reads a JSON file specified by path_to_file. If the JSON contains a list, it returns a numpy array of that list. If the JSON contains a dictionary and dict_key is specified, it returns a numpy array of the data associated with dict_key. If dict_key is not specified, it returns the entire dictionary.

    Parameters:

    Name Type Description Default
    path_to_file str

    Path to the location of the JSON file.

    		 required
    dict_key str

    The specific key to extract data from within the JSON file. If not provided and the JSON is a dictionary, the entire dictionary is returned.

    		 None

    Returns:

    Type Description
    Union[ndarray, Dict[str, Any]]

    Union[np.ndarray, dict]: Depending on the structure of the JSON and the presence of dict_key, returns either a numpy array or a dictionary containing the JSON file data.
