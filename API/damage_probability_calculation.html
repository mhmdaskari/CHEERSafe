    A class used to represent the damage probability calculation engine.

    This implementation utilizes local variables to ensure thread safety. The per–iteration and per–orientation variables (including FailureChecks and DamageRatios) are stored locally. After computing damage probabilities per wind orientation, the results are averaged and saved directly to disk.

    process_component_combination(
    building: Building, ComponentCombination, cIndex: int
) -> tuple

    Process the component combination for a building with parallelization over iterations.

    This method processes a specific component configuration for a building across all wind orientations, wind speeds, and flood depths using Monte Carlo simulation with parallel processing over iterations.

    Parameters:

    Name Type Description Default
    building Building

    The building object to process.

    		 required
    ComponentCombination ndarray

    Retained for compatibility with existing caller signatures.

    		 required
    cIndex int

    The 1-based component configuration index to process.

    		 required

    Returns:

    Name Type Description
    tuple tuple

    A tuple containing (building.BldgType, cIndex, averaged_damage_probability_array), or None if this combination should be skipped based on user filters.
    Notes

    When Config.EXPORT_DETAILED_DAMAGE_RATIOS is True, this method also exports detailed damage ratio breakdowns to a CSV file for each (building_type, cIndex) combination. The CSV file contains damage ratios averaged over Monte Carlo iterations for each (wind_orientation, wind_speed, flood_depth) combination.

    The CSV file is saved to Config.OUTPUTS_PATH with the naming pattern: DetailedDR_m{building_type}_c{cIndex}_iter{NUM_OF_ITERATIONS}.csv

    damage_ratio_exporter #

    Module for exporting detailed damage ratio results to CSV files.

    This module provides utilities for collecting, aggregating, and exporting detailed damage ratio breakdowns from Monte Carlo simulations. The exported CSV files contain per-component damage ratios averaged over iterations.

    Classes:

    Name Description

    DamageRatioExporter dataclass #

    DamageRatioExporter(
    building_type: int,
    cindex: int,
    collected_data: List[Dict[str, Any]] = list(),
)

    Utility class for collecting and exporting detailed damage ratio results.

    This class provides methods to extract component-level damage ratios from DamageRatioCalculation objects and export them as CSV files. Results are averaged over Monte Carlo iterations before export.

    The exported CSV files contain the following columns. - m: Building type identifier - c: Component configuration index - wind_orientation_index: Wind orientation index - wind_speed_index: Wind speed index - flood_depth_index: Flood depth index - dr_total: Total building damage ratio - dr_explicit: Explicit damage ratio (wind components) - dr_implicit: Implicit damage ratio (interior + flood) - dr_exp_wind_RC: Explicit damage ratio for Roof Coverings - dr_exp_wind_RS: Explicit damage ratio for Roof Sheathings - dr_exp_wind_RWC: Explicit damage ratio for Roof-Wall Connections - dr_exp_wind_O: Explicit damage ratio for Openings - dr_exp_wind_W: Explicit damage ratio for Walls - dr_imp_wind_I: Implicit damage ratio for Interior - dr_imp_wind_E: Implicit damage ratio for Electrical - dr_imp_wind_M: Implicit damage ratio for Mechanical - dr_imp_wind_P: Implicit damage ratio for Plumbing - dr_imp_flood: Implicit damage ratio for Flood

    aggregate_and_save_to_csv(

    Aggregate collected data by averaging over iterations and save to CSV.

    This method groups the collected damage ratio records by (wind_orientation_index, wind_speed_index, flood_depth_index), computes the mean of all damage ratio columns over iterations, and saves the result to a CSV file.

    Parameters:

    Name Type Description Default
    output_dir str

    Directory path for output file. Defaults to Config.OUTPUTS_PATH if not provided.

    		 None

    Returns:

    Name Type Description
    str str

    The file path of the saved CSV file.
    Notes

    The CSV file is named using the pattern: DetailedDR_m{building_type}_c{cindex}_iter{NUM_OF_ITERATIONS}.csv

    The 'iteration' column is excluded from the output as values are averaged over all iterations.

    collect_detailed_ratios(
    damage_ratios: DamageRatioCalculation,
) -> Dict[str, float]

    Extract detailed damage ratios from a DamageRatioCalculation object.

    This method extracts all component-level damage ratios from the given DamageRatioCalculation object and returns them in a dictionary with standardized column names for CSV export.

    Parameters:

    Name Type Description Default
    damage_ratios DamageRatioCalculation

    The damage ratio calculation object containing computed damage ratios for all components.

    		 required

    Returns:

    Type Description
    Dict[str, float]

    Dict[str, float]: A dictionary containing all damage ratio values with keys: - dr_total: Total building damage ratio - dr_explicit: Explicit damage ratio - dr_implicit: Implicit damage ratio - dr_exp_wind_RC: Roof Coverings explicit damage ratio - dr_exp_wind_RS: Roof Sheathings explicit damage ratio - dr_exp_wind_RWC: Roof-Wall Connections explicit damage ratio - dr_exp_wind_O: Openings explicit damage ratio - dr_exp_wind_W: Walls explicit damage ratio - dr_imp_wind_I: Interior implicit damage ratio - dr_imp_wind_E: Electrical implicit damage ratio - dr_imp_wind_M: Mechanical implicit damage ratio - dr_imp_wind_P: Plumbing implicit damage ratio - dr_imp_flood: Flood implicit damage ratio
    Notes

    This method accesses the ExplicitDamageRatioWind, ImplicitDamageRatioWind, and ImplicitDamageRatioFlood attributes of the DamageRatioCalculation object to extract component-level values.

    Outputs

    None beyond the returned value.
