    Scenario Creation and Analysis#

    The scenario creation and analysis module provides functionality for creating and analyzing hurricane scenarios and calculating scenario-specific losses.

    Class Diagram#

    classDiagram

        +int time_periods
        +int years
        +np.ndarray hurricane_period_prob

    }
    class ScenarioLossCalculator {
        +str inventory_path
        +RegionalLossEstimator loss_estimator
        +np.ndarray hurricane_loss
