    Loading and Failure Check#

    The loading and failure check module provides functionality for calculating loads on structures and determining failure conditions.

    fn_initial_load_o #

    fn_initial_load_o() -> ndarray

    Calculates the initial wind pressure on each opening (O).

    This method uses the external wind pressure coefficient and building characteristics to determine the initial wind pressure on various types of openings, including doors and windows, based on their location and count in the building structure.

    Notes

    Instance attributes used:

    • qh (float): The external wind pressure coefficient.
    • CCWallGCp (list): The coordinates of the wall's centerline.
    • Building (Building): An object of the Building class, which contains the following used attributes:
      • DoorFront: The number of front doors.
      • DoorBack: The number of back doors.
      • DoorGarage: The number of garage doors.
      • OpeningFront: The number of front openings.
      • OpeningBack: The number of back openings.
      • OpeningSideH: The number of side openings on the edge.
      • OpeningSideR: The number of side openings not on the edge.
    Outputs

    None beyond the returned value.

    Returns:

    Type Description
    ndarray

    np.ndarray: The initial opening load array.

    fn_initial_load_rc #

    fn_initial_load_rc() -> ndarray

    Calculates the initial wind pressure on each panel of roof covering (RC).

    This method derives the initial wind pressure on roof covering panels directly from the calculated initial wind pressure on roof sheathing panels, as the two are closely related in terms of their exposure to wind pressures.

    Notes

    Instance attributes used:

    • pRS (np.ndarray): The initial wind pressure on each panel of roof sheathing.
    Outputs

    None beyond the returned value.

    Returns:

    Type Description
    ndarray

    np.ndarray: The initial roof covering load array.

    fn_initial_load_rs #

    fn_initial_load_rs() -> ndarray

    Calculates the initial wind pressure on each panel of roof sheathing (RS).

    This method takes into account the wind orientation, internal and external pressure coefficients, the coordinates of the roof's centerline, and the area of each pressure zone to determine the initial wind pressure on roof sheathing panels. These factors are essential in accurately assessing the wind loads that affect the structural integrity of the roof sheathing.

    Notes

    Instance attributes used:

    • WindOrientationIndex (int): The orientation of the wind direction.
    • GCpi (float): The ASCE-defined internal pressure coefficient.
    • qh (float): The external wind pressure coefficient.
    • CCRoofGCp (list): The coordinates of the roof's centerline.
    • PressureZoneArea (numpy.ndarray): The area of each pressure zone.
    Outputs

    None beyond the returned value.

    Returns:

    Type Description
    ndarray

    np.ndarray: The initial roof sheathing load array.

    fn_initial_load_rwc #

    fn_initial_load_rwc() -> ndarray

    Calculates the initial wind pressure on each roof-to-wall connection (RWC).

    This method utilizes the area of each pressure zone, internal and external pressure coefficients, and building characteristics including the number of connections, panel counts, roof shape, dimensions, and the coordinates of connections and panels to determine the initial loads on roof-to-wall connections.

    Notes

    Instance attributes used:

    • PressureZoneArea (numpy.array): The area of each pressure zone.
    • GCpi (float): The ASCE-defined internal pressure coefficient.
    • qh (float): The external wind pressure coefficient.
    • CCRoofGCp (list): The coordinates of the roof's centerline.
    • Building (Building): An object of the Building class, which contains the following used attributes:
      • NumConnection: The number of connections in the building.
      • NumPanel: An array containing the number of panels on each side of the building.
      • RoofShape: The shape of the roof.
      • HipRidgeAngle: The angle of the hip ridge of the building.
      • RoofWidth: The width of the roof.
      • BldgLength: The length of the building.
      • BldgWidth: The width of the building.
      • ConnectionCoordinate: The coordinates of the connections in the building.
      • PanelCoordinate: The coordinates of the panels in the building.
    Outputs

    None beyond the returned value.

    Returns:

    Type Description
    ndarray

    np.ndarray: The initial roof-to-wall connection load array.

    fn_initial_load_w #

    fn_initial_load_w() -> ndarray

    Calculates the initial wind pressure on each wall (W).

    This method considers various factors such as the orientation of the wind, gust factor, internal and external pressure coefficients, material weight factors, and building attributes to determine the initial wind loads on each wall.

    Notes

    Instance attributes used:

    • WindOrientationIndex (int): The orientation of the wind direction.
    • G (float): The gust factor, applied to obtain GCp.
    • GCpi (float): The ASCE-defined internal pressure coefficient.
    • qh (float): The external wind pressure coefficient.
    • MWFRSCp (list): The material weight factor for roof, shear wall, and column.
    • pRWC (list): The roof-to-wall connection loads.
    • Building (Building): An instance of the Building class. It uses the following attributes:
      • NumPanel: An array containing the number of panels on each side of the building.
      • RoofWidth: The width of the roof.
      • MeanRoofHeight: The mean height of the roof.
      • WallHeight: The height of the wall.
      • BldgLength: The length of the building.
      • RoofWidth: The width of the roof.
      • Material: The material of the building.
      • RoofShape: The shape of the roof.
      • NumConnection: The number of connections in the building.
      • WallFloorCon_FrontBack: The wall floor connection at the front and back of the building.
      • WallFloorCon_Side: The wall floor connection at the sides of the building.
      • DoorFront: The number of front doors.
      • DoorBack: The number of back doors.
      • DoorGarage: The number of garage doors.
      • OpeningFront: The number of front openings.
      • OpeningBack: The number of back openings.
      • OpeningSideH: The number of side openings on the edge.
      • OpeningSideR: The number of side openings not on the edge.
    Outputs

    None beyond the returned value.

    Returns:

    Type Description
    ndarray

    np.ndarray: The initial wall load matrix.
